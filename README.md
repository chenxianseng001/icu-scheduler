# ICU 排班系统

ICU 科室每周医生排班工具，本地网页应用，**双击即用，零安装**。

## 功能

- 🖱️ **拖拽排班** — 从左侧医生列表拖到排班表，也支持点击分配
- 🤖 **自动排班** — 一键生成合法排班初稿（回溯算法）
- ⚠️ **实时查错** — 缺人、超限、夜班冲突实时标红
- 📊 **按医生查看** — 每个医生一周每日状态一览（白1/白2/夜1/夜2/出/休）
- 📈 **多周统计** — 日历区间筛选，汇总每人白班/夜班/总班次数
- 📥 **Excel 导出** — 一键导出"按医生查看"格式
- 💾 **文件存储** — 数据存本地 JSON，换浏览器/清缓存不丢
- 👥 **医生管理** — 支持增删医生，默认 14 人
- ➕ **灵活班次** — 排班表底部 +白/+夜 额外行，拖入额外医生
- 📅 **日期显示** — 排班表天数旁标注实际日期

## 使用方式

1. 下载 `ICU排班系统-v3.0.zip`
2. 解压到任意文件夹
3. 双击 `启动ICU排班系统.bat`
4. 浏览器自动打开，开始排班

> 需要 Windows 系统（PowerShell 内置，无需额外安装）

## 技术栈

React · TypeScript · Vite · @dnd-kit · xlsx · PowerShell
